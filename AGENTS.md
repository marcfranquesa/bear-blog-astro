# Agent Guidance

## Website PR Verification

For website feature or PR work that affects rendered output, routes, layout,
content, feeds, redirects, or sitemap behavior, run the build, start a local
preview, and inspect the affected pages in a browser or equivalent before the
final response.

In the final response, include the preview URL used for verification, list the
pages/routes inspected, and include the PR or deploy-preview link when
available. If browser inspection or a deploy preview is unavailable, say so
explicitly.
